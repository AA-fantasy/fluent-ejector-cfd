# Fluent case 自检清单（人工版）

> 脚本 `scripts\case_check.py` 能自动核掉的项，这里用 ☑ 标出；剩下的必须在 GUI 里看。
> 建议顺序：先跑 `case_check.py`，再按本清单逐项核对，最后跑 1 步迭代确认不报错。

## A. 打开与拓扑
- [ ] `open_case_gui.bat "xx.cas.h5" "xx.dat.h5"` 能正常打开（无 Error 弹窗）
- [ ] 控制台最后几行有 `Done.`，没有 `Warning: ... adjacent to a solid zone`
- [ ] Outline → General：**2D Space = Axisymmetric** ☑（case_check 也查）
- [ ] Mesh → Info → Size：单元数与网格文件一致（`--case-only` 也能查）☑

## B. 模型
- [ ] Models → Energy：**on**，且 Viscous Dissipation / Inlet Diffusion 按需 ☑
- [ ] Models → Viscous：**k-omega, SST** ☑
- [ ] Materials → air：density = ideal-gas，Cp = 4011.8，k = 0.0261，μ = 1.34e-05，MW = 18.015
- [ ] Operating Conditions：**Operating Pressure = 0** ☑（否则压力要按表压填）

## C. 边界条件（对照 case_check 输出）
- [ ] inlet-primary：pressure-inlet，总压/总温按设计表填（**绝对压**，因为 op pressure = 0）☑
- [ ] inlet-secondary：pressure-inlet，总压取环境压量级、总温按设计表 ☑
- [ ] outlet-mix：pressure-outlet，静压 = 你要扫的背压（绝对），backflow T 按需 ☑
- [ ] wall：stationary、no-slip、thermal = adiabatic
- [ ] axis：type = axis
- [ ] 每个入口的 Turbulence = Intensity 5% + Hydraulic Diameter（按你的入口直径填，case_check 不校验这项）☑
- [ ] 各 zone 名称与几何命名选择**完全一致**（否则换网格时 BC 会丢）

## D. 网格质量（Mesh → Quality / Report Quality）
- [ ] Minimum Orthogonal Quality > 0.1（2D 三角网格建议 > 0.15）
- [ ] Maximum Aspect Ratio < 100（混合室内 < 30 最好）
- [ ] 没有负体积（Mesh → Check 输出 `no negative volume`）

## E. 试跑
- [ ] 不初始化，直接 Iterate 1 步：无 Error、残差有更新
- [ ] 读 data 后看 Residuals：连续性残差已在 1e-4 以下说明是收敛过的解
- [ ] Contours → Static Pressure：喷嘴内高压、混合室亚大气压（不该出现全域同一个压力）

## F. 交付前
- [ ] 存 case + data 两份（`xx.cas.h5` / `xx.dat.h5`），文件名带工况（如 `bg_101`）
- [ ] 记下：跑了几步、残差水平、mp/ms/ω（`omega.py` 输出）
